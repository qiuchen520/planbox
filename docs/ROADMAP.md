| 版本 | 实际交付 |

## 一、核心 UI 架构（底部 5 Tab）

```
┌──────────────────────────────────────────────────┐
│  今日  │  课表  │  日历  │  计划  │  我的          │
│ Today │ Table │ Cal   │ Tasks │ Settings        │
└──────────────────────────────────────────────────┘
```

| Tab | 内容 |
|---|---|
| **今日 Today** | 今日课程、今日待办、倒计时、专注入口 |
| **课表 Timetable** | 周视图、周次切换、单双周过滤、课程卡片 |
| **日历 Calendar** | 月视图按天聚合计划（含重复展开）、点某天看当天清单、当天加计划 |
| **计划 Tasks** | 作业列表、考试倒计时 |
| **我的 Settings** | 统计、导出、节次时间、学期配置 |

> 日历是 v0.4.3 追加的第 5 个 Tab（原规划为 4 Tab），理由是「课表」回答
> 「每周固定上什么」，「日历」回答「这个月哪几天有事」，混在一起两边都不好用。

## 三、坚决不做（避坑清单）

- ❌ 复杂 GTD：无嵌套子任务、无复杂标签体系
- ❌ 社交排行榜：拒绝同辈压力
- ❌ 云同步（前期）：零服务器成本，保护隐私
- ❌ 账号体系 / 收集用户数据
- ❌ 非必要权限（网络、定位、通讯录、无障碍）
