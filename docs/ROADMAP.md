# ROADMAP · 功能规划与分批交付

> 依据 2026-10-17《PlanBox 功能扩展与UI规划》整理
> 原则：**每一批都必须产出一个能装能用的 APK**，不做半成品长期挂机。

---

## 一、核心 UI 架构（底部 4 Tab）

```
┌────────────────────────────────────────────┐
│  今日  │  课表  │  计划  │  我的            │
│ Today │ Table │ Tasks │ Settings          │
└────────────────────────────────────────────┘
```

| Tab | 内容 |
|---|---|
| **今日 Today** | 今日课程、今日待办、倒计时、专注入口 |
| **课表 Timetable** | 周视图、周次切换、单双周过滤、课程卡片 |
| **计划 Tasks** | 作业列表、考试倒计时 |
| **我的 Settings** | 统计、导出、节次时间、学期配置 |

## 三、坚决不做（避坑清单）

- ❌ 复杂 GTD：无嵌套子任务、无复杂标签体系
- ❌ 社交排行榜：拒绝同辈压力
- ❌ 云同步（前期）：零服务器成本，保护隐私
- ❌ 账号体系 / 收集用户数据
- ❌ 非必要权限（网络、定位、通讯录、无障碍）
